Учебный проект по веб-программированию: игровая библиотека в неоновом стиле.
Реализован на чистом HTML, CSS и JavaScript без серверной части и сторонних фреймворков.

## Демо

🔗 **Публичная ссылка:** https://ВАШ-ЛОГИН.github.io/neon-games/

## Возможности

**Неоновый дизайн** с тёмной темой, свечениями и эффектом «глитча» на заголовке.
**Анимированный фон** — светящаяся змейка, которая извивается на Canvas.
**Слайдер** с автопрокруткой, стрелками и точками-индикаторами.
**3D-карточки** — при наведении карточки наклоняются вслед за мышью.
**Обложки игр** — картинки с плавным градиентом, переходящим в фон карточки.
**Фильтр по жанрам** (MOBA, Шутер, Гонки, RPG, Кооператив).
**Модальное окно** с подробным описанием игры, рейтингом, годом, платформой и полным списком персонажей (в 3 колонки, без внутренней прокрутки).
**Блюр карточек** для неавторизованных пользователей с призывом войти.
**Избранное** — у каждого аккаунта свой список, сохранённый в `localStorage`.
**Регистрация и вход** с валидацией формы (email, пароль от 6 символов, подтверждение пароля, согласие с правилами).
**Личный кабинет** — защищён от неавторизованных пользователей, показывает имя, email, дату регистрации и избранные игры с возможностью открыть подробную информацию.
**Адаптивная вёрстка** — 4 → 2 → 1 колонки, бургер-меню на мобильных.
**Плавное появление блоков** при скролле (`IntersectionObserver`).
**Форма подписки** в подвале (с валидацией).


## Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — Grid, Flexbox, CSS-переменные, анимации, `transform-style: preserve-3d`, `backdrop-filter`.
- **JavaScript (ES2017+)** — массивы, функции, `map()`, `join()`, обработчики событий, `localStorage`.
- **Canvas API** — фоновая анимация «змейки».
- **IntersectionObserver** — анимация появления блоков при скролле.

## Как запустить локально

1. Скачай репозиторий (Code → Download ZIP) или склонируй:
git clone https://github.com/ВАШ-ЛОГИН/neon-games.git

2. Открой файл `index.html` в браузере (двойным кликом или через расширение Live Server в VS Code).

## Как добавить новую игру

1. Положи картинку в папку `img/` (например, `img/mygame.jpg`).
2. Открой `js/main.js` и добавь новый объект в массив `MATERIALS` в самом начале файла:
```js
{ id:9, image:'img/mygame.jpg', title:'My Game', category:'Шутер',
  desc:'Краткое описание в одну строку.',
  full:'Подробное описание для модального окна.',
  characters:'Персонаж 1, Персонаж 2, Персонаж 3...',
  rating:'8.0', year:'2025', platform:'PC' }
Сохрани файл и обнови страницу — карточка появится автоматически.
